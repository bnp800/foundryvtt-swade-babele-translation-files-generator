# Product Overview

A FoundryVTT module that generates Babele-compatible JSON translation files from compendium packs.

## Purpose
- Export compendium content (Actors, Items, Scenes, JournalEntries, Adventures, etc.) into translation-ready JSON files
- Support bulk export of multiple compendiums as a ZIP archive
- Merge existing translations with new content to preserve completed work
- Generate custom field mappings for Babele's translation system

## Target Users
- FoundryVTT translators working on system/module localization
- Community members creating language packs for game systems

## Key Features
- Single compendium or bulk export
- Custom mapping definitions per document type
- Existing translation file merging
- Progress tracking during export
- ZIP archive generation for bulk exports
